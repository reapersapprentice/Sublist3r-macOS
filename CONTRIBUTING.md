# Contributing

Thanks for your interest! A quick note on how this repository works.

**Pull requests are welcome, but they are reviewed and merged _solely by the author_ (C.Studva).**
This is a personally maintained project. Opening a PR is a *suggestion*, not a change —
nothing is merged without my review, and I may decline changes that don't fit the
project's direction.

- 🐛 **Bug or idea?** Open an issue (if enabled) or a small, focused PR that explains **what** and **why**.
- ✅ Keep changes minimal and self-contained.
- ⚖️ This is a **macOS conversion** of an existing open-source tool — please respect the
  original project's license (see `LICENSE` / `NOTICE`) in anything you submit.

Maintained by **C.Studva**.
